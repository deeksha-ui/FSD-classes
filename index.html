Bash Commands I Have Learnt

1.touch

File creation

The touch commmand creates a new, empty file.If the file alredy exists, it simply updates the file's last-modified timestamp instead of changing it's content.
It's one of the simplest ways to create a file directly from terminal.

Syntax:touch filename

Example:touch notes.txt

Output:(no output- the file notes.txt is created silently in the current folder)

2.mkdir

Folder creation

The mkdir command creates a new, empty folder(directory) at the location you specify.

Syntax:mkdir foldername

Example:mkdir project

Output:(no output- the folder project is created in the current directory)

3.cd

Changing directory

The cd command changes the current working directory, moving you into a different folder in the termilnal.

Syntax:cd foldername

Example:cd project

Output:(no output- prompt changes to show that you are now inside ~/project)
